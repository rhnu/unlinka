# Unlinka

[English](README.md) | [简体中文](README.zh-CN.md)

Windows 快速删除工具，提供 CLI 和 Windows 原生确认窗口。Unlinka 支持永久删除、终端确认、扫描预览、有界并发、取消和失败汇总。

删除不会进入回收站。取消只停止尚未开始的工作，不能恢复已经删除的项目。

## 使用

以下示例均假设 `unlinka` 已在 `PATH` 中。Unlinka 面向 Windows 10/11，不需要管理员权限或额外 GUI 运行时。目前没有安装器和 Explorer 右键入口。

```powershell
unlinka --help

# 弹出 Windows 原生确认窗口；取消为默认按钮
unlinka -r .\node_modules

# 在交互式终端中确认
unlinka -r --confirm console .\node_modules

# 在脚本中明确跳过确认
unlinka -r --yes .\node_modules

# 仅扫描并统计，不修改目标，也不请求确认
unlinka -r --dry-run .\node_modules

# 删除多个目标；线程预算包含扫描线程
unlinka -r --threads 8 .\one .\two

# 处理以短横线开头的文件名
unlinka -- -example
```

普通目录必须显式使用 `-r`。符号链接、junction 和其他重解析点作为入口处理，不递归扫描其目标。`--threads` 范围为 1–64，默认取 CPU 可用线程数与 4 的较小值。预算为 1 时同步执行；更大的预算分配一个扫描线程，其余线程执行删除。扫描时就可以删除已发现的文件，不等待整棵目录树统计完毕。

原生确认失败时，Unlinka 会报告错误。需要终端确认时显式使用 `--confirm console`。终端模式要求交互式 stdin 和 stderr，空回答拒绝删除。`--yes` 与显式 `--confirm` 不能同时使用。

结果与诊断输出至 stderr。普通执行计数为成功删除的文件、目录和链接入口；dry-run 计数为扫描到的候选项。汇总给出耗时和失败总数，最多列出 100 个具体失败。执行时可以按 Ctrl+C 取消，Unlinka 不能恢复已经删除的项目。

| 退出码 | 含义                                   |
| ------ | -------------------------------------- |
| 0      | 完成且无失败，或 dry-run 扫描完成      |
| 1      | 执行失败或部分失败                     |
| 2      | 参数错误或目标预检查失败，尚未开始删除 |
| 3      | 用户取消；执行阶段可能已经删除部分内容 |
| 4      | 确认窗口或确认输入失败，尚未开始删除   |

## 边界

Unlinka 不修改只读属性、不提权，也不结束占用文件的进程。执行前会重新验证所有顶层目标，任一目标无法打开或身份变化时整批停止。执行中的权限或共享冲突作为失败返回，其他独立项目继续处理。保护路径包括卷根、Windows 目录及其内容、用户目录、当前工作目录及相关祖先。这些保护不能替代其他重要数据的备份。

预检查记录目标身份，执行前重新打开并复核。扫描时通过目录句柄限制常规写入与重命名，并复验目录类型，报告共享冲突而不忽略。新增文件可能导致目录非空失败；文件若在打开前被替换，同名的新文件仍可能被删除。叶子项通过已打开句柄删除，即使另一进程随后将它移出所选目录，仍处理这个已选对象。仅修改属性的重解析点操作仍有检查与打开之间的竞争窗口。Unlinka 不提供隔离恶意并发修改的保证。

目前不包含回收站删除、右键菜单、精确百分比进度、自动重试、占用进程处理，以及保留目录本身的清空模式。主要优化目标是本地 NTFS 的大量小文件；其他文件系统及网络路径尚未验收。原生窗口使用系统任务对话框，布局可能与不同 Windows 版本的 Explorer 有所区别。
